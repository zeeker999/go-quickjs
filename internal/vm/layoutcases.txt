# The register interpreter's hot cases: where each starts in runReg, an
# offset from the loop's start, in a build of internal/cmd/v8bench made as
# the layout lock's targets are (layoutlock.txt), for each configuration.
# With the lock's lever Q pinning runReg's start, a case's address modulo
# 4 KB is decided by the code before it in the loop alone; the hot cases
# come first in runReg's switch and every other case after them, so that
# only an edit to a hot case moves another. TestLayoutLock fails where a
# hot case is not where this file says; a deliberate edit to one rewrites
# the offsets with go generate ./internal/vm (internal/cmd/layoutpad,
# which reads them from the build's dispatch table) and is timed.
#
# The hot line names them: the fewest operations covering 95% of the
# dispatches over the V8 suite, Octane and Are We Fast Yet in register
# mode, each benchmark weighted alike, and every operation 5% or more of a
# micro-benchmark's (docs/register-interpreter.md, "The loop").
